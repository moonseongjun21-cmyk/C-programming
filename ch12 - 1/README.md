# 실습과제1

16MB 메모리의 주소의 범위를 구하시오.
0 ~ 16,777,215

변수의 주소를 설명하시오. 
변수가 차지하고 있는 공간의 시작 번지(가장 작은 주소)

변수의 주소의 자료형은 무엇인가? 
변수선언: int i 주소: &i 주소의 자료형: int* 

포인터란 무엇인가? 
주소를 저장하기 위한 변수

포인터의 자료형은 무엇인가? 
포인터 앞의 자료형*

변수의 주소를 int형변수에 저장하면 어떻게 되는가?
포인터가 아닌 int형 변수에 저장하면 오류가 날 수 있습니다.
