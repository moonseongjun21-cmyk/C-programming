# 실습과제1

1.함수선언, 호출, 정의를 각각 설명하라.

함수선언 : 컴파일러에게 뒤에 나올 함수를 미리 알려주는 것

호출 : 정의된 함수를 실행하는 것

정의 : 함수의 실제 동작을 작성하는 부분

2.함수의 자료형은?

반환 형과 매개변수의 자료 형으로 정의

ex) 반환형(매개변수 자료형1, 매개변수 자료형2, …)

3.함수 명의 자료형은?

(함수의자료형)* -> (반환형(매개변수 자료형1, 매개변수 자료형2, …))* -> 반환형 (*)(매개변수자료형1, 매개변수자료형2, …)

4.void 포인터의 용도는?

하나의 포인터로 모든 종류의 주소를 저장할 수 있음

void포인터에 간접참조연산을 적용할 때 주의 할 점은?

void포인터에 연산을 적용할 때 에는 반드시 강제형변환하여 가리키는 자료형을 정의한 후 사용해야함

강제형변환과 자동형변환을 설명하시오.

강제형변환 : 개발자가 직접 원하는 자료형으로 변환하도록 명시하는 방식입니다.

자동형변환 : 프로그래밍 언어에서 작은 자료형을 큰 자료형으로 변환할 때, 컴파일러가 자동으로 처리하는 변환을 말합니다.
