# 실습과제1

프로그램 개발과정 편집->선행처리->컴파일->링크->실행 단계를 자세히 설명하시오.

편집
---
C언어로 컴퓨터가 처리할 작업을 기술하여 소스코드를 작성 

텍스트에디터(editor)를 이용하여 작성.

소스파일(source file)
---
소스 코드가 들어 있는 텍스트 파일(확장자가*.c)로서 편집 단계의 결과물

선행처리 : 컴파일 과정 전에 선행처리(preprocessing) 단계가 있음

선행처리 과정에서 소스파일에 헤더파일을 포함시키거나 일부 문장을 다른 문장으로 바꾸는 작업 등 특별한작업을 수행

선행처리가 끝난 결과 역시 C언어로 작성된 소스파일임

선행처리를 수행하는 프로그램을 선행처리기(preprocessor)라고 부름

컴파일
---
C언어로 작성된 소스 코드를 기계어(이진수)로 변환하는 단계

오브젝트 파일(object file, 목적파일) : 기계어로 변환된 파일, 확장자가obj -> 예) test.obj

컴파일을 수행하는 프로그램을 컴파일러(compiler)라고 부름

링크
---
오브젝트 파일들을 라이브러리 파일들(목적파일)과 연결하여 하나의 실행 파일을 생성하는 단계

실행 파일(executable file) : 실행이 가능한 기계어로 작성된 파일, 확장자가exe -> 예) test.exe

라이브러리(library): 프로그램을 만들 때 많이 사용되는 기능을 미리작성해놓은것(printf, scanf 등) -> 목적파일 형태로 존재

링크를 수행하는 프로그램을 링커(linker)라고 부름

실행
---
실행파일의 내용을 컴퓨터가 수행하는 단계

로더(loader) : 실행파일을 주기억장치(RAM)로 로드(load)하고 실행 시켜주는 프로그램

간단한 예제 프로젝트 빌드 후 소스파일(c), 목적파일(obj), 실행파일(exe)의 위치를 찾아보라-> 파일탐색기 검색화면을 캡쳐하여 첨부할것.

파일탐색기에서 보기옵션에서 확장자가 보이도록 설정하고 캡쳐할것.
