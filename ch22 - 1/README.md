# 실습과제1

1.구조체가 필요한 이유를 설명하라.

서로 다른 종류의 데이터를 묶어 사용하면 관리가 편리하기 때문입니다.

2.배열과 공통점과 차이점을 설명하라.

어떤 데이터를 묶어 사용할 수 있다는 점은 동일하나 구조체는 서로 다른 종류의 데이터(자료형)도 묶어 사용할 수 있습니다.

3.기본자료형과 구조체의 차이를 설명하라.

구조체는 여러 자료형을 묶어 구성할 수 있습니다.

4.구조체 정의와 구조체 변수 선언의 의미를 각각 설명하라.

구조체 정의는 구조체의 멤버변수들을 정의하는 것이고 정의 후 구조체 변수 선언을 하면 멤버변수들이 메모리에 할당됩니다.
