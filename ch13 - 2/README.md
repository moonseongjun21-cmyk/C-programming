# 실습과제1

배열선언과 동시에 초기화하는 방법과 포인터변수에서 초기화하는 방법이 있습니다.

널문자의 용도를 설명하라.
배열의 끝을 알려주는 용도

문자열 끝의 메모리 값이 0인 곳을 찾으면 됩니다.

문자열의 길이를 구하는 알고리즘을 설명하라.
끝이 널문자이므로 배열 값의 첫 번째 문자부터 널문자가 나올때까지 차례대로 출력합니다.
